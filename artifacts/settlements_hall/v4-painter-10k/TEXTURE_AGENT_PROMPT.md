# Задание для раскраски Settlements Hall V4 Painter 10k

Работай с моделями и UV из ЭТОГО архива. Прочитай README.md и открой
settlements_hall.blend. Это готовая модель на 10 805 треугольников.
Не перестраивай модель, не меняй геометрию, координаты UV, pivots или анимации.

Создай только цветные PBR albedo без запечённого освещения и теней:
1. main_paint.png, 2048×2048: тёплый белый известняк, тёмно-синие двери,
   сине-бирюзовое стекло с тонким мозаичным рисунком, синяя ткань.
2. roof_paint.png, 2048×2048: тёмно-синяя/teal металлическая кровля,
   спокойные крупные поверхности и деликатные швы.
3. trim_paint.png, 2048×2048: состаренная латунь, светлое каменное основание,
   умеренная каменная разбивка площадки.

Стиль: premium stylized tabletop diorama, original VorGun/Telanico.
Сохрани силуэт и существующую архитектуру. Не добавляй новые балки, декор или
перекладины над входом. Guide и checker не являются готовой текстурой.

Три материала-атласа выбираются через свойство paint_atlas / узел PAINT_ATLAS.
Используй *_layout.png / *_guide.png / *_key.png / surface_mapping.csv/json
как точные ориентиры. Одинаковые повторяющиеся части намеренно делят UV,
список экземпляров находится в intentional_repeat_uvs. Не двигай острова.
Не переноси раскраску по старым UV V3 или по картинке isometric.png.

Сохрани исходные металлические/шероховатые свойства и Alpha стекла.
Не подключай непрозрачный alpha холста к стеклу. Сохрани две дверные петли,
четыре полотна, три морф-цели каждого полотна и все четыре именованных клипа.
Экспортируй через указанный в README штатный экспортёр с явным путём вывода.

Верни три PNG без подписей и сетки, упакованный .blend, самостоятельный .glb
с вложенными текстурами, один изометрический рендер и короткую заметку.
Не вноси изменения в игру и не выполняй деплой.
