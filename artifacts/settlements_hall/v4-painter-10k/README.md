# Settlements Hall V4 — Painter 10k

Отдельная облегчённая версия первого белого здания с синим куполом.
**10 805 треугольников вместо 19 816: на 45,47% меньше.**
Игра и установленная V3 Lite не изменены. Это экстерьерная модель: нового
доступного интерьера здесь нет. При крупном плане упрощения профилей видны.

## Что открывать

- `settlements_hall.blend` — редактируемые части, исходные PBR-материалы,
  индивидуальные дверные петли и четыре морф-анимированных полотна.
- `settlements_hall.glb` — отдельный экспорт, точно совпадающий с этими UV.
- `isometric.png` — настоящий Blender-рендер с исходными материалами.
- `mapping_front.png`, `mapping_rear.png` — соответствие модели и UV-областей.
- `comparison_v3_v4.png` — старый и новый вариант с одинакового ракурса.
- `TEXTURE_AGENT_PROMPT.md` — готовое задание агенту для раскраски.

## Три атласа, каждый 2048 × 2048, UV0

| Атлас | Поверхности | Чистые контуры | Подписанная схема |
| --- | --- | --- | --- |
| MAIN | фасады, колонны, окна, двери, четыре флага | [main_layout.png](main_layout.png) | [main_guide.png](main_guide.png) |
| ROOF | купол и кровли крыльев | [roof_layout.png](roof_layout.png) | [roof_guide.png](roof_guide.png) |
| TRIM | металлические детали, карнизы, каменное основание и площадка | [trim_layout.png](trim_layout.png) | [trim_guide.png](trim_guide.png) |

Разделение даёт фасадам больше разрешения: около 72 px/m для MAIN,
57 px/m для ROOF и 37 px/m для TRIM; плотность едина внутри каждого атласа.
Купол разделён на восемь крупных секций. Контуры и подписанные схемы используют
**одни и те же сохранённые координаты**, без повторного repack. Между границами
упакованных областей оставлено не менее 12 пикселей.

`*_paint.png` — пустые белые холсты для раскраски. Не меняйте размеры и UV.
`*_wire.png` — все рёбра Blender, растеризованные из настоящего `*_native.svg`.
`*_key.png` — полный список ID и названий; `surface_mapping.csv/json` —
соответствие объектов, полигонов и атласов. `*_checker.png` — временный
диагностический рисунок с ID, он не подключён к финальным материалам.

Одинаковые повторяющиеся окна и колонны **намеренно используют общие UV**:
рисовать повторяющийся узор достаточно один раз. Все такие экземпляры перечислены
в `intentional_repeat_uvs` файла JSON и в CSV. Непреднамеренные пересечения
проверены между треугольниками. Двери и анимированные флаги не объединялись.

## Как применить текстуры

Рисуйте отдельным слоем поверх `*_paint.png`, используя контуры/guide как
заблокированный ориентир. Уберите контуры, надписи и checker перед сохранением.
В каждом материале записан `paint_atlas` и есть неподключённый узел `PAINT_ATLAS`.
Подключите его Color к Principled Base Color, сохранив Metallic/Roughness.
Для полноценного цветного атласа уберите повторное умножение на старый цвет
в Godot; стеклу сохраните прежнюю Alpha и прозрачный режим. Белый alpha
покрасочного холста не должен делать оконное стекло непрозрачным.

После ручной правки экспортируйте из открытого .blend существующим скриптом:

```sh
blender -b settlements_hall.blend --python /path/to/Telanico-3D-Lab/blender/scripts/export_settlements_hall.py -- --output /your/output/settlements_hall_painted.glb
```

Клипы: `Doors_Open`, `Doors_Close`, `Flags_Wind-loop`, `Hall_Demo-loop`.
Не объединяйте дверные створки и полотна со статичной геометрией.
Старые UV V3 Lite не совместимы с этим комплектом — текстурируйте именно V4.

`checks.json` и `godot_import_check.json` содержат выполненные проверки.
Исходная V3 Lite, карта, маршруты, сценарий и опубликованная игра сохранены.
