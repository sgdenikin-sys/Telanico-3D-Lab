# Transport V2 — painting kits

Use the V2 Blend/GLB included in each kit. These layouts do **not** match V1 models in the live game.
Geometry, hinges and door clips are preserved; the game/runtime has not been changed.

| Model | MAIN layout | MAIN guide | TRIM layout | Complete kit |

| Pneumatic station | [PNG](pneumatic_station/main_layout.png) | [Guide](pneumatic_station/main_guide.png) | [PNG](pneumatic_station/trim_layout.png) | [ZIP](pneumatic_station_painting_kit.zip) |
| Commuter ferry | [PNG](commuter_ferry/main_layout.png) | [Guide](commuter_ferry/main_guide.png) | [PNG](commuter_ferry/trim_layout.png) | [ZIP](commuter_ferry_painting_kit.zip) |
| Harbor launch | [PNG](harbor_launch/main_layout.png) | [Guide](harbor_launch/main_guide.png) | [PNG](harbor_launch/trim_layout.png) | [ZIP](harbor_launch_painting_kit.zip) |

Both atlases are 2048×2048. MAIN contains large connected painting regions;
TRIM contains independently unwrapped metalwork and hardware. Chart IDs match
the keys, CSV and model checker previews. Clean/annotated versions share coordinates.

Paint on `main_paint.png` / `trim_paint.png`; use the guide as a separate locked
reference layer and hide it before exporting. Keep canvas dimensions unchanged.
Each model README explains the ready image nodes and preserved glass opacity.
