# Painted transport V2 — owner-supplied package

Source: [Telanico_Three_Models_Painted_V2.zip](https://drive.google.com/file/d/1kzpi0QpXAMSzsEg5X5oxPgjvg8z011uM/view).
Downloaded through the corresponding individual Drive model folders.

Each model directory preserves the supplied packed `.blend`, MAIN/TRIM PNGs
extracted unchanged from its embedded GLB, and source/hash metadata.
The ready-to-run GLBs are in `godot/assets/generated/transport/`.

All original V2 geometry/UV buffer views and node/mesh/animation declarations
were compared byte-for-byte with the painter kits before installation.
No placement, route, story, material redesign, UV repacking or asset rebuild.
Previous V1 and V2 painting kits remain preserved in their own directories.
