## Release path

The owner explicitly authorized shipping the working V2.2 and deferring broken
components. The existing public repository and Pages deployment are retained.
The reviewed product source is 2c94a3f687e7174340360885e069336b73cf599e.
The existing local Windows machine builds it with the official Godot 4.6.3 editor
and matching single-thread release template. Blender 5.2.2 rebuilt the models.
No new hosting service, credential, runner or private-source publication is used.

`tools/bootstrap_release.py` downloads the official pinned editor and reads only
the Web template from the official multi-platform ZIP using HTTP byte ranges.
`tools/build_windows_release.py` executes the existing validation/native/audio
gates and Web export, logging each result under ignored build/logs/.
`tools/stage_web_release.py` requires desktop and complete phone browser passes,
checks an exact runtime allowlist, preserves the V2.1 site locally and records
SHA-256 hashes of the replacement snapshot.
`tools/verify_live_web.py` checks actual HTTPS metadata and exercises real
desktop/touch opening, office, invoice, assistant and menu interactions.

Local build metadata deliberately says source_run_id=local; the failed private
Action is never presented as a successful source artifact. The public Pages
workflow independently verifies snapshot hashes before deployment. The previous
manual private importer remains available for explicit V2.1 rollback; it is not
scheduled and is not invoked for this workstation release.

## Repeat on Windows

Use a working Python interpreter and pass the installed Blender executable:

```powershell
python tools/bootstrap_release.py
python tools/fetch_assets.py
python tools/build_windows_release.py --blender '<path-to-blender.exe>'
```

The portable toolchain and all generated files stay under ignored build/ and
generated asset directories. The builder preserves previous Web snapshots under
build/web-history/ on subsequent runs. Browser verification additionally requires
Playwright 1.58.0 and its Chromium browser; this release installed them under
ignored build/pydeps/ and build/browsers/. Local evidence logs and screenshots
remain there; their hashes are recorded in evidence/live-release-20261023.json.
